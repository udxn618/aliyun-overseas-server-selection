## 200M 带宽是"限峰值"，下单前必须弄清这一点

200M 指的是限峰值带宽，不作为业务承诺指标。业务高峰期出现资源争抢时，公网带宽可能受到限制，官方文档对此写得明白，这一点恰恰是很多推广文章不提的。

## 常见问题

### 阿里云境外服务器需要备案吗？

不需要。中国香港及全部海外节点均无需 ICP 备案，购买后可直接绑定域名对外访问；只有中国大陆地域的服务器需要备案。

### 为什么网络速率达不到套餐标注的峰值带宽？

因为标注值是峰值，是带宽上限而非常态承诺。高峰期资源争抢时公网带宽可能被限制，这是轻量套餐低价策略的一部分，对带宽有硬性保障需求的应改用 ECS 固定带宽。

### 大陆访问境外节点会很慢吗？

会明显偏慢。非中国内地地域提供的是国际带宽，从大陆访问延迟较大；需要兼顾大陆访客时优先选香港，它离大陆最近，且移动、联通直连。

### 买错地域或想换配置怎么办？

地域不支持更换，只能退订重买；配置支持在同节点内升级 CPU、内存和系统盘，不支持降级。新购享有五天无理由全额退订。

### 支持哪些系统和应用镜像？

系统镜像包括 Alibaba Cloud Linux、CentOS、Ubuntu、Debian、Windows Server 等主流系统；另有 24 款应用镜像可一键部署，例如 WordPress、LAMP、Docker、Node.js、宝塔面板，以及内置 WordPress 的 WooCommerce 电商模板，省去手动配环境的时间。
